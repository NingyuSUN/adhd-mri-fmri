# TRIPOD+AI reporting gap map

Based on the [2024 original statement, Table 2](https://pmc.ncbi.nlm.nih.gov/articles/PMC11019967/). This is a 27-item planning map, not certification or a completed 52-subitem manuscript checklist. PARTIAL means artifacts exist but manuscript reporting remains incomplete; NOT VERIFIED means not established in the reviewed package. Project assessments below are our own.

| Item | Topic | Status | Project action |
|---|---|---|---|
| 1 | 标题 | PROPOSED | 明确 ADHD-200 回顾性模型评估及增量价值。 |
| 2 | 摘要 | NOT VERIFIED | 尚需正式结构化摘要及摘要清单。 |
| 3 | 背景 | PARTIAL | 补临床用途、目标人群、既有模型和不平等背景；不承诺诊断应用。 |
| 4 | 目标 | VERIFIED | 协议与主比较明确；区分预定分析和事后敏感性。 |
| 5 | 数据 | PARTIAL | 补采集日期、来源许可及代表性说明。 |
| 6 | 参与者 | PARTIAL | 补中心、纳排及药物处理的最终方法文字。 |
| 7 | 预处理 | PARTIAL | 代码可追踪；原始 MRI 复现和专家完整 QC 未验证。 |
| 8 | 结局 | NOT VERIFIED | 核实诊断标准、评估人员及盲法的原始资料。 |
| 9 | 预测变量 | PARTIAL | 协议/源码存在；补测量与评估者描述。 |
| 10 | 样本量 | PARTIAL | 队列计数已存；需有限样本精度说明，不能用重复预测增加人数。 |
| 11 | 缺失 | PARTIAL | 需逐变量缺失率和排除理由的稿件表。 |
| 12 | 分析 | PARTIAL | 提供代码、区间和敏感性；明确单次内层划分偏离及聚合目标。 |
| 13 | 不平衡 | NOT VERIFIED | 逐模型核实权重/重采样与校准处理。 |
| 14 | 公平性 | NOT VERIFIED | 不能把多站点评估等同公平性评估。 |
| 15 | 输出 | PARTIAL | 分数已复现；正式说明阈值来源及概率解释范围。 |
| 16 | 训练/评估差异 | PARTIAL | LOSO 与 QC 表存在；补人口学分布对照。 |
| 17 | 伦理 | NOT VERIFIED | 作者提供批准/豁免与同意依据。 |
| 18 | 开放科学 | PARTIAL | 版本/锁文件/协议具备；补资助、利益冲突、注册事实和共享许可。 |
| 19 | 公众参与 | NOT VERIFIED | 作者确认有无参与，不能推定没有。 |
| 20 | 样本结果 | PARTIAL | 站点计数具备；补流程图、特征及缺失表。 |
| 21 | 分析人数 | PARTIAL | 66 单元记录存在；稿件汇总训练/选择/测试人数及事件数。 |
| 22 | 模型规格 | PARTIAL | 复现代码存在；明确未交付一个临床部署最终模型。 |
| 23 | 性能 | PARTIAL | AUC、校准与站点异质性已存；亚组与临床效益尚不充分。 |
| 24 | 更新 | PROPOSED | 作者确认是否适用；不得把敏感性分析称为外部模型更新。 |
| 25 | 解释 | PARTIAL | 使用当前统计解释；补文献比较和公平性讨论。 |
| 26 | 局限 | VERIFIED | 当前审计已列有限样本、QC、选择不稳定和外推边界。 |
| 27 | 使用/后续 | PROPOSED | 限研究用途；补输入失败处理和外部验证计划。 |
