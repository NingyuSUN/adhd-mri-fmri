# TRIPOD+AI reporting gap map

Based on the [2024 original statement, Table 2](https://pmc.ncbi.nlm.nih.gov/articles/PMC11019967/). This is a 27-item planning map, not certification or a completed 52-subitem manuscript checklist. PARTIAL means artifacts exist but manuscript reporting remains incomplete; NOT VERIFIED means not established in the reviewed package. Project assessments below are our own.

| Item | Topic | Status | Project action |
|---|---|---|---|
| 1 | Title | PROPOSED | State that this is a retrospective ADHD-200 model evaluation of incremental value. |
| 2 | Abstract | NOT VERIFIED | A formal structured abstract and the abstract checklist are still needed. |
| 3 | Background | PARTIAL | Add the clinical use case, target population, existing models and inequality context; make no commitment to diagnostic use. |
| 4 | Objectives | VERIFIED | Protocol and primary comparison are explicit; prespecified analyses are separated from post hoc sensitivity analyses. |
| 5 | Data | PARTIAL | Add acquisition dates, source licensing and representativeness. |
| 6 | Participants | PARTIAL | Add final methods text on sites, inclusion/exclusion and medication handling. |
| 7 | Data preparation | PARTIAL | Code is traceable; reproduction from raw MRI and complete expert QC are not verified. |
| 8 | Outcome | NOT VERIFIED | Verify the source records for diagnostic criteria, assessors and blinding. |
| 9 | Predictors | PARTIAL | Protocol and source code exist; add descriptions of measurement and assessors. |
| 10 | Sample size | PARTIAL | Cohort counts exist; add a finite-sample precision statement. Repeated predictions must not be counted as additional participants. |
| 11 | Missing data | PARTIAL | A manuscript table of per-variable missingness and exclusion reasons is needed. |
| 12 | Analytical methods | PARTIAL | Code, intervals and sensitivity analyses are provided; state the single inner-split deviation and the aggregation target. |
| 13 | Class imbalance | NOT VERIFIED | Verify weighting/resampling and calibration handling for each model. |
| 14 | Fairness | NOT VERIFIED | Multi-site evaluation must not be presented as a fairness assessment. |
| 15 | Model output | PARTIAL | Scores are reproduced; formally state the threshold source and the scope of probability interpretation. |
| 16 | Training versus evaluation | PARTIAL | LOSO and QC tables exist; add a comparison of demographic distributions. |
| 17 | Ethical approval | NOT VERIFIED | The authors must provide the approval/exemption and consent basis. |
| 18 | Open science | PARTIAL | Versions, lock files and protocols are available; add funding, conflicts of interest, registration status and sharing licenses. |
| 19 | Patient and public involvement | NOT VERIFIED | The authors must confirm whether there was involvement; absence cannot be assumed. |
| 20 | Participants (results) | PARTIAL | Site counts are available; add a flow diagram, characteristics and missing-data tables. |
| 21 | Model development | PARTIAL | Records for the 66 units exist; the manuscript should summarize training/selection/test participants and event counts. |
| 22 | Model specification | PARTIAL | Reproduction code exists; state explicitly that no final model for clinical deployment is delivered. |
| 23 | Model performance | PARTIAL | AUC, calibration and site heterogeneity are available; subgroup and clinical-benefit evidence is insufficient. |
| 24 | Model updating | PROPOSED | The authors must confirm applicability; sensitivity analyses must not be described as external model updating. |
| 25 | Interpretation | PARTIAL | Use the current statistical interpretation; add literature comparison and fairness discussion. |
| 26 | Limitations | VERIFIED | The current audit lists finite-sample, QC, selection-instability and extrapolation limits. |
| 27 | Usability and implications | PROPOSED | Restrict to research use; add input-failure handling and an external validation plan. |
